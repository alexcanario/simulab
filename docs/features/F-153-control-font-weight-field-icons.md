# Control font weight and trailing field icons

Technical terms: [glossary](../glossary.md)

## Summary
The kit's controls (text, select, lookup and suggest fields, buttons, option rows) use a lighter font weight, as in the Stitch reference screen; only titles and headings keep today's heavy weight. The field icons move to the right end of the control, as the arrow of the reference screen's selects. Source: discussion D-6 (2026-10-24); the icon part reverts the D-4 decision of 2026-10-17 that kept the field icons of the current kit, at the owner's request.
