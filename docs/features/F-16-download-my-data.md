# Download my data

## Summary
A signed-in user downloads everything the app holds about them, in a machine-readable file (portability, LGPD article 18 / GDPR article 20). Left out of F-10 (account erasure) on 2026-09-19 because Identity holds only the email, the display name, the preferred language and the consent records. Worth building when there is a study history to export: attempts, answers, scores and the coach's conversations.
