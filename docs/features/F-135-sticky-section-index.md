# Sticky section index on long forms

Technical terms: [glossary](../glossary.md)

## Summary
A long form shows a numbered index of its sections (for the question form: Classification, Statement, Base text, Options, Explanation) that stays at the top while the page scrolls, highlights the current section and jumps to a section on click. It is a kit pattern, shown on the gallery, for any form with section cards. It came from the Stitch reference screen (D-4). In-page links must follow the `shell.js` rule of `ui-project.md` (`<base href="/">`); F-120 is the related architecture test idea.
