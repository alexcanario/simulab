# Orthogonal layout for entity diagrams

## Summary
The entity diagrams generated by DocGen (`docs/architecture/<Module>/entities.md`) use Mermaid's default layout, with curved relation lines. The owner finds an orthogonal layout (right-angle lines) clearer and more useful. In Mermaid, an `erDiagram` gets orthogonal edges from the ELK layout (`config: layout: elk` in the block's front matter). Before building, verify that the owner's viewer, the VS Code Markdown preview, renders ELK, and what it shows when it does not. Requested by the owner while validating B-12 (2026-09-22).
