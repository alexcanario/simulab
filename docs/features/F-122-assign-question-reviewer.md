# Assign a reviewer to a question

Technical terms: [glossary](../glossary.md)

## Summary
When a question is sent for review, the author or a curator can pick a specific reviewer (a user who holds the review permission); that person sees the question first in the review queue. F-105's queue is shared by every reviewer, with no assignment. Captured at the F-105 refinement (owner, 2026-10-16). Source: epic Question bank (E-4).
