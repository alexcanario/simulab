# Keyboard shortcuts on forms

Technical terms: [glossary](../glossary.md)

## Summary
Forms answer to keyboard shortcuts and show them on their buttons as keycaps: save (Ctrl+S), the screen's main action (Ctrl+P on the question form) and jumping between sections (Alt+1 to Alt+5). It came from the Stitch reference screen (D-4) and fits the keycap identity of F-125. Conflicts with browser shortcuts (Ctrl+P prints, Ctrl+S saves the page) and with screen readers are unknown — settled at /agile:refine.
