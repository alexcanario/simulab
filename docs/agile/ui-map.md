## Terms
| Term | Meaning (pt-BR) |
|---|---|
| sidebar | menu lateral esquerdo |
| base text | texto-base: um texto que várias questões usam, escrito uma vez |
| picker | seletor: o campo em que se escolhe um texto-base ao editar a questão |
| type card | cartão de tipo: cada um dos cartões do campo "Question type" (Single choice, True/false, Multiple answer, Matching, Fill in the blanks) |
| matching key | gabarito de associação: o cartão "Matches" com a coluna numerada "Items" (cada linha com seu seletor de letra) e a coluna com letras "Matches" |
| Insert blank | Inserir lacuna: o botão da barra do editor do enunciado (só no tipo Fill in the blanks) que escreve o próximo marcador [[n]] onde está o cursor |
| blanks section | seção de lacunas: o cartão "Blanks" que substitui o cartão Options no tipo Fill in the blanks, com uma linha "Blank n" por marcador do enunciado e as respostas aceitas de cada uma |
| Summary aside | coluna Resumo: a caixa ao lado do formulário da questão, com os dados, a lista "Before publishing" e, no fim, o bloco "Publication" com as ações de publicação |
| amber key | tecla âmbar: o botão âmbar com borda mais escura e um ícone; na questão é o "Publish", o único botão âmbar da tela |
| checklist | lista "Before publishing": o que falta para a questão poder ser publicada, ao lado do formulário |
| review queue | fila de revisão: a lista das questões enviadas para revisão, da mais antiga para a mais recente |
| in review | em revisão: a questão foi enviada, está congelada e espera uma decisão |
| reviewer-only role | papel só de revisão: um papel criado na tela de papéis que tem apenas a permissão "Review questions" |
| app bar | barra superior: a faixa no alto de todas as páginas, com o menu, a marca e os botões de tema, idioma e usuário |
| theme switch | botão de tema: a lua (ou o sol, no tema escuro) no canto superior direito da barra superior |
| UI gallery | galeria do kit: a página de desenvolvimento que mostra cada peça do kit de interface |
| chip | etiqueta: uma pílula arredondada que mostra um item (aqui, uma entrada do mapeamento de uma disciplina do edital) |
| notice subject | disciplina do edital: uma matéria como o edital a nomeia e agrupa, com o número de questões |
| syllabus | conteúdo programático: a lista de disciplinas do edital que o aluno abre sob cada edição no catálogo |
| notice PDF | PDF do edital: o arquivo PDF do edital de uma edição, guardado dentro do Simulab, além do link oficial |
| file field | campo de arquivo: o campo "Notice PDF" do formulário da edição, com Choose PDF, Replace e Remove |
| alternative text | texto alternativo: o texto de uma imagem lido em voz alta para quem não a vê; "Imagem decorativa" dispensa o texto |
| image dialog | diálogo de imagem: a janelinha "Insert image" aberta pelo botão de imagem da barra do editor, com arquivo, prévia e texto alternativo |
| row actions | ações da linha: os botões de ícone no fim de cada linha de uma lista (Editar, Excluir e, quando há, outros) |
| Where used dialog | diálogo "Onde é usado": a janelinha que lista as disciplinas do edital que usam uma disciplina ou um tópico e, para um tópico, quantas questões o usam |
| access dialog | diálogo de acesso: a janelinha "Acesso de …" aberta pelo lápis (Editar papéis) na linha de um usuário, com os papéis marcáveis e o campo Tenant |
| tenant | tenant: a organização parceira a que uma conta pertence, identificada por um id longo (GUID) |
