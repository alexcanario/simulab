# Jobs — data dictionary

Generated from the EF model. Do not edit. Schema: `jobs`.

## jobs

Entity: `Job` — Work that must happen but must not make a request wait, such as sending an email. A job that succeeds leaves no row.

| Column | Type | Null | Key | Default | Notes |
|---|---|---|---|---|---|
| id | uuid | no | PK |  | Identifier of the row, a UUID v7: generated by the app, ordered by creation time. |
| attempts | integer | no |  |  | How many times a worker has started it. The first attempt makes it 1. |
| created_at | timestamp with time zone | no |  |  | When the job was enqueued, in UTC. The worker takes the oldest first. This is not an audit field: the queue is not audited. |
| last_error | character varying(2000) | yes |  |  | max 2000; The message of the last failure, kept with a failed row. Cut so one bad job cannot fill the table. |
| payload | text | no |  |  | The whole input of the job, as JSON. Cleared when the job is given up on: the message is a live link and an address, not evidence. |
| run_after | timestamp with time zone | no |  |  | Not to be run before this instant, in UTC. Set at enqueue and pushed forward by the retry backoff. |
| started_at | timestamp with time zone | yes |  |  | When the current attempt started, in UTC. A row stuck here is taken again by another worker. |
| status | integer | no |  |  | What the row is doing: 0 waiting for its turn, 1 a worker is running it, 2 every attempt failed. There is no value for success, because a job that succeeds leaves no row. |
| type | character varying(100) | no |  |  | max 100; Which handler runs the job. The worker matches it against the handlers registered in the host. |

Indexes:
- `ix_jobs_active_created_at` on created_at (where status IN (0, 1))
